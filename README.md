## 文件用途

| 文件 | 用途 |
| --- | --- |
| RAW.pdf | 原始PDF，保留原貌；补采与其他原始格式另存RAW_补采NNN.* |
| MD.md | PDF的Markdown转写，保留页码定位并标注缺图、裁切等问题 |
| META.json | 来源、作者、永久文章ID、采集校验值、转换与加工记录 |
| AI_短标题.md | 本人下载或明确要求生成的AI学习笔记；已有总结保留 |
| NOTE.md | 开始记录时使用90_templates/个人笔记模板.md创建，由本人填写 |
| PROMPT.md | 本文实际取得的全部Prompt，合并单文件 |
| SKILL.md | 本文实际取得的全部Skill，合并单文件 |

可选文件仅在有内容时出现，文章内不创建额外的source或run目录。已有RTFD原始附件包整体保留。MD转写完成不表示PDF图片、版面或在线原文全部核验通过，详情见各篇META.json。
