# 文章处理规则与模板入口

执行规则统一维护在根目录 [agent.md](../agent.md)。当前文章在 inbox 原位整理，公众号 README 展示索引，根 README 提供学习入口。

- [就地文章索引参考](文章索引模板.md)：公众号索引与实际产物链接。
- [个人笔记模板](个人笔记模板.md)：用于 NOTE.md，保留本人原话与真实记录。
- [Prompt模板](Prompt提炼模板.md)：明确需要时整理同篇 Prompt，区分原文与AI说明。
- [Skill模板](Skill提炼模板.md)：明确需要时整理同篇 Skill，不代表已安装或验证。
- [主题笔记模板](主题笔记模板.md)：有来源依据时组织跨文章归纳，不代填个人理解。

以下仅适用于库外历史归档格式，当前 inbox 使用已有采集元数据：

- [META模板](META.template.json)：旧文章的来源、采集、加工与转换记录。
- [采集记录模板](capture.template.json)：旧 META.json 的 captures 数组记录。

历史格式不作为重新迁移 inbox 或恢复已移出旧材料的要求。
