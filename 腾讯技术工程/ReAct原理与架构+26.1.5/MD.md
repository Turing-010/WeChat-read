⼀、什么是 ReAct ？
2022 年，普林斯顿⼤学和⾕歌的研究团队在论⽂《 ReAct: Synergizing Reasoning and Acting
in Language Models 》中提出的 ReAct 范式，通过构建 “ 推理 - ⾏动 - 观察 ” （ TAO ）的闭环机制，
⾸次实现了语⾔模型推理能⼒与外部环境交互能⼒的深度协同，为解决上述瓶颈提供了⾥程碑
式的⽅案。
ReAct = Reasoning （推理） +  Acting （⾏动），本质是⼀种让语⾔模型通过与外部⼯具、环
境动态交互完成复杂任务的智能体架构范式。其核⼼⽬标是打破传统语⾔模型 “ 输⼊ - 输出 ” 的
单向链路，构建 “ 感知 - 决策 - 执⾏ - 反馈 ” 的智能闭环，使模型从 “ 被动应答者 ” 升级为 “ 主动问题
解决者 ” 。
在⼈⼯智能的演进历程中，⼤语⾔模型展现出了令⼈惊叹的⽂本⽣成能⼒，但其 “ ⿊箱 ” 特
性也带来了显著挑战 —— 模型经常产⽣看似合理但实际错误的 “ 幻觉 ” 回答，缺乏透明推理
过程，且⽆法与外部世界交互获取实时信息。ReAct （ Reasoning+Acting ）通过将思考过
程外显化和⼯具使⽤标准化，构建了⼀个可解释、可验证、可扩展的智能体架构。本⽂将
深⼊剖析 ReAct 的核⼼原理、技术架构及其对整个 AI 领域的深远影响。

与传统 AI 技术相⽐， ReAct 具备三个核⼼特征：
1. 显式推理轨迹：模型在执⾏⾏动前会⽣成可追溯的 “ 推理过程 ” （ Thought ），清晰说明⾏动

2. 外部环境锚定：通过调⽤搜索、计算、数据库查询等外部⼯具（ Act ）获取客观反馈

3. 少量样本泛化：依托 LLM 的上下⽂学习能⼒，仅需 1-5 个包含 “ 推理 - ⾏动 - 观察 ” 的完整⽰

从技术本质来看， ReAct 并⾮单⼀算法，⽽是 “ 语⾔模型 + ⼯具集 + 循环调度机制 ” 的集成架构。
其核⼼创新在于将⼈类解决问题的认知模式（分析 - 操作 - 反馈）抽象为机器可执⾏的框架，使
AI 具备了⾃主拆解任务、动态调整策略的能⼒。
⼆、核⼼思想与设计理念
2.1 核⼼思想：模拟⼈类认知的 TAO 闭环
ReAct 的核⼼思想源于⼈类解决复杂问题的认知过程：当⾯对 “ 规划⼀次跨城旅⾏ ” 这类任务
时，⼈类会先分析需求（推理），再执⾏查机票、订酒店等操作（⾏动），最后根据航班余票、
酒店价格等反馈（观察）调整计划，形成循环。 ReAct 将这⼀过程抽象为 “Thought （推理）
→ Act （⾏动）→ Observe （观察） ” 的 TAO 闭环，其中：
Thought ：模型的 “ 内⼼独⽩ ” ，⽤于分析任务⽬标、历史反馈和当前状态，明确下⼀步⾏
动的逻辑依据；
Act ：模型与外部交互的 “ 执⾏动作 ” ，如调⽤搜索引擎、计算⼯具或控制设备；

五、 ReAct 解决了什么问题？
ReAct 范式的核⼼价值在于针对性解决了传统 AI 技术在复杂任务中⾯临的四⼤关键痛点，显著

5.1 破解传统 LLM 的 “ 事实幻觉 ” 难题
传统 LLM 的推理完全依赖预训练阶段习得的内部知识，当⾯临实时信息（如最新政策、实时数
据）、专业领域知识（如医疗诊断、法律条款）时，极易⽣成与事实不符的 “ 幻觉内容 ” 。
ReAct 通过 “ ⾏动调⽤外部权威⼯具→观察获取客观事实→推理整合事实 ” 的链路，将推理过程
锚定到真实数据。实验数据显⽰，在 Fever 事实核查任务中， ReAct 的幻觉率仅为 8.2% ，远低
于纯思维链（ CoT ）的 23.5% 。
