⼀ 、 任务背景

图像质量评估（   Image Quality Assessment, IQA）旨在 建⽴符合⼈ 类视觉系 统（Human
Visual System, HVS）感知特性的 图像质量评价模型。 随着AIGC等图像⽣成技术的 ⻜速发
展，对 IQA模型的 需求与 ⽇ 俱增，同时 对 其性能要求也愈发严苛。 然⽽，传统       IQA模型通常
只能提供⼀ 个 笼统的质量分数 。 这 种“知其然，⽽不知其所以然”的单⼀ 评分⽅式，存在 结果
维度单⼀ 、 可解释性差及泛化能⼒有 限等核⼼局限。 尽管业界已有 研究尝试使⽤模型对 图像
的 优点与 不⾜进⾏概括性描述，但针对 图像进⾏细粒度质量分析，例如对 失真区 域进⾏精准
定位，以及评估特定失真在 图像中 的 视觉表现和 对 ⼈ 类视觉感知的影响仍然鲜有 ⼈ 涉⾜。

ViDA-Grounding，分别从图像描述、 感知和 失真定位三个 维度对 模型进⾏提问，并设有 不

1. 图像感知（Perception）： 包含2567道选择题，采⽤感知准确率（Perception

2. 失真定位（Grounding）： 设计了两个⼦任务，均使⽤ mAP 指标进⾏评估。

  1. 失真定位(distortion)： 模型需输出所有失真区域的边界框。

3. 图像描述（Description）： 模型输出需遵循四个步骤：

  1. 简要描述图像内容。

  2. 定位所有失真，并分析其对特定区域的影响。
  3. 分析整体图像质量与视觉观感，并识别出关键失真。

  4. 总结图像质量，给出⼀ 个总体质量等级。

此任务使⽤ Description mAP 评估步骤2，使⽤ Key Distortions Accuracy（与真实关键
失真框 IoU > 0.5即视为正确）评估步骤  3，使⽤ Image Quality Accuracy 评估步骤4。
