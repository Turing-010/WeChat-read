块；进⼀步地，领域专属模板也优于通⽤模板（ BLEU-4 0.0801 →  0.0858 ），印证了 " 内容感
知专门化 " 思想在⽣成端同样成⽴。
3.3.3 多源特征注⼊（ Multi-source Feature Injection ）
仅靠视觉信号， MLLM 在⾯对极相似的图像对时仍容易 " 看不出差别 " ，凭直觉给出模糊判断。
为此，团队在⽂本输⼊中显式注⼊两类质量相关特征，作为可量化的辅助证据：
⦁传统  CV 统计量： Laplacian 、 Tenengrad 、噪声标准差、⾼频⽐、边缘密度、熵、曝光相关
⽐、⾊彩度、平均亮度；
⦁ 学习型  IQA 指标： LIQE 、Q-Align 、 SAMA 。
这些特征按 " 图像对  × 裁剪粒度 " 格式化后追加到  User Prompt ，作为结构化辅助证据。这种
Feature-aware Prompting 让模型推理同时锚定在视觉观察与数值测量上，对细微画质差异更
敏感，也降低了 " 凭直觉乱猜 " 的概率，在更难的细粒度对⽐中尤其有效。两类特征也具有天然
互补性：传统  CV 统计量提供低层、可解释的物理量，学习型  IQA 指标提供⾼层、与⼈类感
知对齐的语义打分，⼆者结合让推理更加稳健。
3.3.4 Answer-aware 指令微调（ Answer-aware Instruction Tuning ）
最后，团队引⼊了  Answer-aware 监督作为最终的 " 理由精修 " 阶段：把  Answer Model 给出的
⽬标答案显式写⼊  Prompt （例如   Ground truth: Left is better.  ），模型不再重复预测  Answer
Token ，⽽只⽣成⽀撑该结论的推理过程。这⼀设计有两层意义：⼀⽅⾯避免了模型⾛捷径式
的 " 答案复制 " ，把⽣成容量从 " 猜答案 " 中解放出来；另⼀⽅⾯强迫模型学习更强的 " 证据  →  结
论 " 对齐关系，确保理由真正服务于结论⽽⾮⾃说⾃话。本质上，这⼀阶段相当于  Rationale
Reﬁnement—— 在判别能⼒已被  Answer Model 兜底的前提下，让  Thinking Model 把全部容
量都⽤于把 " 理由 " 讲得更连贯、更与  Label ⼀致，让双分⽀真正实现 " 判别归判别、解释归解
释 " 的协同闭环，也使  iDiﬀ 在  ACC 与推理质量两端同时拿到稳定增益。
