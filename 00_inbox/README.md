# 收集入口

新收到的PDF、网页导出文本或附件放在这里。待归档不表示材料完整。

归档到“公众号/短标题+26.8.20/”，分配永久article_id并保存在META.json。原始PDF为RAW.pdf，转写为MD.md；补采保留capture编号及校验值，不覆盖旧材料。确认归档文件和记录有效后再清理相应收集箱原件。

META.json分别记录来源完整性、转换／加工状态及本人阅读状态；未知时间和网址留null。NOTE.md在本人开始记录时按个人笔记模板创建；AI总结由本人后续添加。

处理规则见[agent.md](../agent.md)。
